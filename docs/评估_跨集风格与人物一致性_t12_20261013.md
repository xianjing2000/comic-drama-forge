## 2. 缺口 · 跨集会漂移的地方（逐项 + 证据）

### 2.1 【重点】第 N 集的角色参考图：**复用，不是重新生成**（已实测证伪"必然漂移"）

> 任务书最担心的风险点。结论：**不成立**——参考图是项目级、跨集逐字节相同。

只读探针（在真实生产数据上直接调用生产函数 `asset_refs._build_asset_index` + `qc_helpers._pick_char_view`）
对第 1/2/3 集分别建索引并取图，逐文件算 sha256：

| 角色 | 第1集取到 | 第2集取到 | 第3集取到 | sha256[:16] |
|---|---|---|---|---|
| 羡进 | `.../羡进/base.png` | 同 | 同 | `08a7a8be105cc00b` |
| 赵天霸 | `.../赵天霸/base.png` | 同 | 同 | `90f135dbbd74e1db` |
| 林清雪 | `.../林清雪/base.png` | 同 | 同 | `5769d40154751a06` |
| 外门围观弟子 | `.../外门围观弟子/base.png` | 同 | 同 | `0688bfef0a2e4cbb` |
| 张铁柱 | `.../张铁柱/base.png` | 同 | 同 | `ea7354b5fe48d67a` |
| 李天风/王二牛/王虎/莫问天 | （无图，`None`） | （无图） | （无图） | — |

落盘证据：`assets/characters/逆天系统_全书/{羡进,赵天霸,林清雪,外门围观弟子}/base.png` 的
`LastWriteTime` 全是 **2026-10-12 01:45–01:50**（第1集生产时段），第2集（22:18–22:26）只新增了
张铁柱 base.png 与 3 个场景；即**第1集角色没有被第2集重画**。
（`.local/_t12…` 探针原始输出另存：`t12_pickview.txt`。）

**但仍有两个真实风险点**：

- **R1｜资产"全量重生成"会静默改写全项目形象基准**：`overwrite=True` 时
  `asset_worker.py:730` 的跳过分支失效 → 第 N 集会**重画并覆写 episode 1 的 base.png**，
  此后所有集（含补跑）都变成新形象。这条路径确实存在：`app/routes/assets_api.py` 的资产生成入口
  暴露 `overwrite`（`asset_worker.py:389/396-397` 明写「overwrite=True 时强制全量重生成」）。
  这是"用户点一下 → 历史集形象全变"的无提示风险。
- **R2｜新角色在第 N 集首次定妆，无跨集校验**：第3集新增 王虎/李天风/王二牛/莫问天
  （`bible.json` 里 `first_episode: 3`），它们的 base.png **当时还不存在**（现在磁盘上仍只有
  `outfits/ep03_*/outfit.json`，没有 base.png）。它们的长相由第3集那一刻的随机 seed 决定；
  没有"与第1/2集先出现的人同框图是否协调"的任何检查。当前数据里 4 个角色都只在第3集出现，
  所以没有"同角色跨集换脸"的实证；但这属于**结构性风险**（一旦角色在第2集以配角先出现、第5集再当主角，
  没有任何机制阻止形象差异）。

另外两处"参考图缺失"的静默路径（会削弱身份锚定）：
- `_build_asset_index` 会给**没有图的角色目录**也建 entry（`index.image=None`）→
  `_pick_char_view` 返回 `""` → 该角色**整条参考图链静默跳过**（`qc_helpers.py:346 if not img: continue`），
  不置 `_no_reference`、不报错。实测 EP2/EP3 的 6 个角色里有 4 个处于这个状态（第3集尚未出资产）。
- `asset_refs.py:346-359`：参考图槽位只有 9 个、角色身份槽位 3 个，超出的角色只进文字说明。

### 2.2 服装（outfit）按集变化时，来源不统一

- 登记侧统一（`continuity._register_outfit_variants`），但**消费侧只有视频链路**：
  `_episode_outfit_overrides` 的调用点只有 `video_helpers.py:1410`（`shot["character_outfits"] = ...`）。
- 分镜链路 `qc_helpers._shot_outfit_dir:161` 只认 `shot["outfit"]` / `shot["character_outfits"]`，
  而**实测第1/2/3集剧本里这两个字段全为空**（0/46、0/39、0/39）→ 分镜恒取主 base.png，
  `outfits/<key>/` 的换装图在**分镜阶段根本用不上**，只在 H3 视频阶段生效。
  → 后果：**同一集里，分镜图穿主设定服、视频换成衣柜变体**（服装不一致发生在链路内部，不只是跨集）。

### 2.5 风格：项目级，但**没有色调锚点**

- style 串项目级、逐集复用（`style_guide.json: reuse_by_episode [1,2,3]`），画幅/分辨率项目级
  （`storyboard_megapixels()`、`style_kit.resolve`），模型来自工作流模板（非风格决定），
  这些**集间一致**。
- **LoRA 不是集间一致的锚点**：`h3_segment_loras.select_loras_for_shot_smart(shot)`（`video_helpers.py:592/1301`）
  **逐镜**调 LLM 选 LoRA（`h3_segment_loras.py:343/392`，`temperature=0.3`，`strength` 允许 0.6~0.8 浮动），
  无缓存。→ 同一场戏跨集可能挂到不同 LoRA / 不同强度；因为最终画面是"扩散 + 参考图"产物，
  这属于**风格抖动源**，不是"人物漂移"，但确实逐集可能不同。
- **没有统一的色调锚点**：唯一存在的画面级衔接是**集内**的「上一镜衔接」
  （`storyboard_helpers.py:1951-1975`，取 `out_dir/shot_NN.png`）与视频侧「上一场末镜」
  （`video_helpers.py:1463-1496`）；`_qc_prev_shot_ref`（`qc_helpers.py:713`）用的是**本集 out_dir**，
  **第 N 集第 1 镜拿不到第 N-1 集末镜**。跨集的画面级锚点**不存在**。
- 量化（1664×928 九宫格，逐格主色相/均色；脚本见 `t12_quant_probe.py`）：

  | 指标 | 数值 |
  |---|---|
  | 第1集 vs 第2集 全图均色距离（RGB 欧氏，0–441） | **61.8** |
  | 第1集团内 镜间均色距离 | 58.95（std 31/28/29，n=46） |
  | 第2集团内 镜间均色距离 | 21.87（n=5） |
  | 对比度（lum P95–P5）第1集 / 第2集 | 140.4 / 109.5 |
  | 单张九宫格内 9 格主色相散度（最大） | 第1集 185°（shot_30：25–210°）、第2集 178°（shot_01：30–208°） |

  解读（**样本量声明**：第1集 46 张分镜图、第2集仅 5 张，第3集 0 张，故"跨集"比较只有 1 组可用）：
  「跨集差异（61.8）」**不超过「同一集内部的镜间差异（59.0）」** → 现有数据支撑"跨集色调确实换了，
  但换的幅度与集内本来就有的抖动量级相当"。逐格看更直白：EP1 shot_03 九格全在 24–34°（橙褐），
  EP1 shot_04 九格全在 180–185°（青调），EP2 shot_01 九格从 30° 跳到 208° —— **同一镜内**就横跨冷/暖。

- 视觉复核（vision，EP1 shot_03 / EP1 shot_04 / EP2 shot_06 三图对比）：
  主角羡进「脸型/五官像同一人、发型发色一致、服装款式颜色一致、没有换脸换装」——
  即**在已锚定的角色上，跨集人物一致性实际是成立的**；被模型判为"浅灰/米白"的服装
  与"青色"的文字设定并不完全吻合（这正是 §2.3 的文本漂移在起作用）。

### 2.6 「已经建好但没接通」的现成机制（"接通而非新建"的答案）

## 3. 方案建议（分层 + 成本）

### L0｜低成本（接通/加护栏，0.5–1 人日；**几乎不含新组件**）

1. **给"全量重生成资产"加跨集护栏**（R1）：
   - 入口处若项目已存在 `bible.json` 且 `episodes_seen` 含更早集 → 明确二次确认文案
     「这会改写第1集起全项目的人物形象基准」；
   - 或者更彻底：把角色定妆基准落到 `asset_lib`（已存在）并让"重生成"默认写**新指纹**而非覆盖旧目录
     （复用 `asset_library.store/lookup`，属接通）。
2. **让分镜链路与视频链路用同一套服装覆盖**（§2.2）：把 `_episode_outfit_overrides` 的调用从
   `video_helpers` 提到 `_storyboard_worker._prep_shot` 同位置（消费端 `_shot_outfit_dir` 已就绪）。
3. **修 `_allocate_storyboard_refs` 的静默跳过**：角色命中资产但无图时，除了 `_ref_warnings` 追加
   可见告警，避免"该角色整条身份链静默消失"（现在只有"未匹配"才告警，"有目录无图"不告警）。

### L1｜中成本（接通 + 数值校验，2–4 人日）

4. **接回跨集画面锚点**：把已存在的 `keyframe.prev_episode_end_frame` 语义搬到分镜链路：
   第 N 集第 1 镜（且同场景群/时间连续时）把第 N-1 集末镜分镜图作为一张参考图
   （`storyboard_helpers.py:1951` 那段"上一镜衔接"的现成写法 + 目录逻辑已由
   `tests/test_cross_episode_chain.py` 钉死：第2集在项目根、第3集在 ep02）。
   成本主要在**条件判定与槽位纪律**（9 槽上限），不在新代码。
5. **跨集一致性数值校验器**（软告警，不阻断）：
   - 复用现有 QC 落盘历史（`output/qc/<项目>/image_N.json`）；
   - 比对项：① 每个角色的 `_pick_char_view` 路径 **sha256 是否与第1集相同**（这是最便宜的强判据，
     一次 hash 即可，且我们已经证明它现在是相同的，正好用来自动守住 R1）；
     ② 每集/每场次的全图均色与主色相 vs 第1集基准的偏移是否超阈值（本次实测基线：跨集 61.8、
     集内 59.0，阈值需先标定，建议"跨集偏移 > max(集内 p90, 80)"再报）；
   - 输出到既有 `metadata.continuity`（新增一个 `cross_episode` 段）与质量面板，
     与"跨集一致性"面板项（`docs/设计_前端UIUX契约_T25_20261012.md:139`）对齐。
6. **文本层服装漂移的收敛**：把 `reconcile_outfit_with_shots` 的镜头改写从"仅识别长服装短语 + 配色冲突"
   扩展到"角色名窗口内的所有配色词"（当前实测漏 12→ 实际 30+），或至少在还原不动时**产出可见告警**。

### L2｜高成本（新建能力，1–3 周）

7. **人物资产库（角色三视图/服装套装）+ 跨集一致性打分与自动重试**：
   - 三视图：角色 sheet 已产出（`comfyui_client._CHARACTER_SHEET_EN_LAYOUT`），但 2026-10-02 起
     **不再切分**（`_pick_char_view` 只给整图），要重建"逐视角档"需回到切分链路；
   - 服装套装：衣柜机制已具备（登记/出图/消费），缺的是"按集×角色×场景"的套装编排与统一来源；
   - 一致性打分与自动重试：需要先有可靠的脸部 embedding（当前只有 VLM 判官，抖动大、
     `test_t5_paneldup_independent` 就在测同一类问题），建议**先做 L1 的 hash/色调校验**，
     拿到稳定性数据再决定是否需要自动重试闭环。

## 4. 推荐方案（排期建议）

**先做 L0 的三条（半天到 1 天）**——它们都是"接通既有机制/加护栏"，直接消掉两个真实风险：
 全量重生成改写全项目形象基准（R1）； 分镜与视频服装不一致； 角色无图时身份链静默消失。

**再做 L1 的 4/5 两条（2–3 天）**：跨集首镜画面锚点（把 2026-10-10 用户已经点名要过的
"第1集末帧传到第2集首镜"在**分镜层**补上，测试用例现成）+ 跨集一致性数值校验（hash + 色调）。

**L2 暂不启动**：当前证据不支持先投人物资产库——因为"人物一致"这一层**本来就是成立的**
（§2.1 实测同哈希 + §2.5 视觉复核"像同一人"）；把钱先花在**文本漂移收敛**与**风格/色调锚点**上收益更高。

### 工作量与风险

| 项 | 工作量 | 主要风险 |
|---|---|---|
| L0-1 重生成护栏 | 0.25 人日 | 改变用户既有操作习惯（需 UI 文案）；若做成"写新指纹"会多占磁盘 |
| L0-2 分镜接衣柜 | 0.5 人日 | 变体图未生成（ep03 现在 4 个 pending）会回落主图，行为等价，零回归 |

| L1-5 跨集校验器 | 1–2 人日 | 阈值误报（本次实测跨集 61.8 vs 集内 59.0，**差距很小**，说明单靠均色不足以判"风格漂移" → 必须先标定，或改用"与第1集同角色参考图 hash 一致"这个强判据打底） |
