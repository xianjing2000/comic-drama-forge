# 配音 与 角色生成 · 缺陷核验与同类借鉴（2026-10-16）

> 方法：三路只读核验（**配音代码** / **角色代码** / **联网调研同类**）；缺陷均带 `文件:行号`（已抽查复核承重项）。
> 定位：为「配音功能」与「角色生成功能」找出**真缺陷**并对齐**同类项目做法**，给出按 ROI 的动作清单。**本文件不改代码**。

## 0. 一句话结论

- **配音**：模型侧音色控制链路**已相当扎实**（历史最刺眼的「全员同声 / 指空槽」都已**结构性根修**）。真缺口集中在两处：① **H3 音频参考槽位硬上限 = 3**（平台限制，第 4 个角色起锁不住音色，短剧 4–9 角色是常态）；② **音色正确性没有任何自动判据**——质检只有客观电平层（只挡「整段无声」），拦不住「音色串味 / 全员同声 / H3 自编嗓子」。另有一簇**参考音色生成偏脆弱**的小缺陷（失败无重试、改人设不失效）。
- **角色**：架构已从「三视图切分」整体转向「**整图 + 文字锁**」，但**改造只做了一半**：切分链路成**死代码**、半身档配置成**空壳**；最扎眼的是 **HD 增强又把四区整图「硬三等分」**、还把这个**错误裁切**当分镜出图的**首选身份锚点**。跨集「连戏」缺**画面级锚点**（`state_out` 只到视频层）。

## 1. 配音功能

### 1.1 架构对齐（别搞错）
成片音轨**不是**先 TTS 出整集配音再对轨，而是 **MiniMax H3 视频模型自带原生音轨**（`audioMode=generate`：模型按参考音色自生成对白）。`tts_pre` 只做「**每角色一段参考音色**」→ `voice_bank/<角色>/ref.wav` → H3 锁音色。旧 `tts`（逐句 QwenTTS）/`mix` 已下线（`pipeline.py` STEP_SEQUENCE 不含它们）。**所以「配音」产物只有每角色一段 `ref.wav`，主链路没有逐句配音可检。**

### 1.3 同类借鉴（配音）
| 借鉴点 | 来源 | 对本题价值 |
|---|---|---|
| **多角色对白：逐句 speaker 绑定参考音频** | **Fish-Speech**(S2-Pro/Drama 3) · IndexTTS/CosyVoice2 的 `spk_audio_prompt` | 工程上最通用：建「角色→参考音频/embedding」注册表，逐句按 speaker 选参考音。**直接对应 V1（>3 角色）**：把「H3 全局 refAudios 3 槽」换成/补充为**逐段注入该段说话人的参考音**，绕开全局 3 槽 |
| **音色/情感解耦 + 时长可控** | IndexTTS-2.5（`emo_*` + `duration_factor`） | 「同角色跨段音色不变、情绪可变」+ 便于口型对齐 |
| **音色一致性门禁：speaker embedding 余弦** | **WeSpeaker**（ECAPA/CAM++） | **补 V6/V7**：对同角色跨段音频算声纹余弦，低于阈值报警 |
| **词级时间戳 / 说话人分离** | **WhisperX**（wav2vec2 对齐 + pyannote diarize） | 校验「逐句 speaker 归属」、音画同步、字幕 |
| **音质客观分** | SpeechMOS(UTMOS)/PESQ | 音质门禁（可选） |
| **口型（若引入）** | MuseTalk1.5（**8GB/30fps+**）· HunyuanVideo-Avatar 的 FAA（多角色独立注音频）· InfiniteTalk（无限长） | 若放弃「H3 原生音轨」路线，人声可走 TTS→口型 |

**同类对「视频模型自带音轨」的共识**：原生音轨**可控性差**（难精确指定每角色音色、多角色难区分），实践建议「**native audio 只做环境音/氛围，人声走 TTS+音频驱动视频**」。⚠️ 对 H3 是否也如此，官方未公开细节 → **待核实**（这对 V1 是根因级判断）。

### 1.4 建议动作（配音，按 ROI）
1. **补音色一致性门禁（最高 ROI、可离线）**：新增 `.workbuddy/test/verify_voice_consistency.py` 风格脚本——对 `voice_bank/<角色>/ref.wav` 与成片里该角色的音频段算 **speaker embedding 余弦**（WeSpeaker/ECAPA），低于阈值报警。**补 V6/V7**，纯离线、零生产风险。
2. **参考音色生成加固**：V3 加**重试**（1–2 次，短超时）；V4 加「**人设变更 → ref 失效**」判据（人设 `voice_style`/文本变了就重生成）+ 暴露「重做音色」入口（`force=True` 接线）。
3. **>3 角色降级策略（V1）**：短期——**拆集**规避（分集让每集出场角色 ≤3）；或把「全局 3 槽」改为**逐段注入该段 speaker 参考音**（借 Fish-Speech 思路，但要确认 H3 段级 `refAudios` 语义，**需 PoC**）。
4. **V2 latent 冲突**：给 `check_ref_layout` 补「段级与全局并存」的**显式判定**（当前直接 return）。
5. （可选）**口型/TTS 路线评估**：若原生音轨音色可控性长期不够，评估「QwenTTS/CosyVoice2 出人声 → MuseTalk 对口型」——**架构级，需先拍板**（见 §4）。

4. **离线守卫是否接进门禁**（像 `verify_storyboard_diversity` 那样 `--strict` 退出码非 0）。
