# 三问诊断：分镜重复 / 失败反复 / 官方提示词对照（2026-10-09）

## 问 1：前端两集分镜图重复 —— **你的判断是对的，是隔离问题**

### 实锤

    D:\...\output\storyboards\夜航灯_两章\
        shot_07.png / shot_07.meta.json / storyboard_manifest.json
    没有 ep01/ ep02/ 子目录；manifest 里 total=9（只有 9 镜，不带集信息）

### 根因（代码级）

`app/routes/_shared.py`：

    def _ep_dir(base_dir, episode_no=None):
        ep = int(episode_no or 1)
        if ep <= 1:
            return base_dir                      # 第 1 集写到项目根（历史兼容）
        return os.path.join(base_dir, f"ep{ep:02d}")

    def _ep_read_dir(base_dir, project, episode_no=None):
        flat = os.path.join(base_dir, project)
        d = _ep_dir(flat, episode_no)
        if os.path.isdir(d) and d != flat:
            return d
        return flat if os.path.isdir(flat) else d   # ← 问题在这：对第 2+ 集也回落到第 1 集目录

**第 2 集还没产出时**，`ep02/` 不存在 → 直接回落到第 1 集的平铺目录 →
前端/接口把第 1 集的分镜图当成第 2 集的产物展示 → **两集看起来完全一样**。

### 已修（待重启生效）

把回落**严格限定在第 1 集**（历史兼容的真实目标只是「第 1 集平铺时代的旧数据」）：

    第1集 旧/新 = P / P              （兼容保留）
    第2集 旧     = P                 ← 错：落到第 1 集目录
    第2集 新     = P\ep02            ← 对：返回本集空目录
    第2集已产出 新 = P\ep02

影响面：`_ep_read_dir` 有 11 处调用（storyboards / videos / keyframes / consistency / qc / quality），
同一处修复对**视频、关键帧、质检**的集级展示同样生效。

## 问 2：失败次数为什么这么多 —— **教训只在沉淀，没有回流到分镜生成**

### 教训确实在沉淀：本项目已 16 条

    storyboard 类（九宫格雷同为主）：score 38–50，从 17:24 一直报到 18:24，反复 5 次
    prompt 类（提示词缺段）：score 84，反复 10 次
      「缺少『动作与画面内容』段」「缺少『景别（必须严格遵守）』段」

### 但分镜链路**没有接**教训回流

`prompt_memory.learned_prompt` 的调用点：

    app.py:2272   资产（asset）
    app.py:5873   视频（video）
    app.py:8121 / 8632 / 8934   （其它链路）
    script_generator.py:127   剧本
    keyframe.py:474           关键帧

**分镜链路（app.py 5300–6400）一处都没有** —— 而教训库里 storyboard 类的每一条都在讲
分镜该怎么改。「沉淀了却不用」正是同类失败反复出现的原因。

### 另外 10 条 prompt 类反复出现，指向生成侧与质检侧的**结构口径不一致**

这些 prompt 正文里其实有动作、有景别（「呈现中近景：林昭立于画面左侧…」），
但质检要求的是**带段落标签**的格式（「动作与画面内容」段、「景别（必须严格遵守）」段）。
生成侧不写标签、质检侧按标签要 → 每镜必报 2 条，且**自愈也补不上**（自愈只补文字/字幕约束）。

## 问 3：参考官方提示词文档 —— 查到官方来源，且它**解释了九宫格雷同的根因**

### 官方来源

    Qwen-Image-2.1 官方发布   https://qwen.ai/blog?id=qwen-image-2.1   （2026/09/20，QwenTeam）
    Qwen-Image-Edit-2511 官方 Prompt guide   huggingface.co/Qwen/Qwen-Image-Edit-2511/discussions/7
    第三方实用指南   blog.segmind.com/qwen-image-prompt-parameter-guide

### 官方要点（原文摘录）

    · 统一 文生图 + 图像编辑，7B 视觉生成组件；
    · **最多 10 张参考图**（up to 10 reference images）—— 与我们 `<Picture 1..N>` 的用法一致；
    · 原生透明通道、改进的**文字排版**（typography）；
    · 提示词风格建议：**Simple and Clear — 用简洁平实的语言说明主体、风格、情绪**；
      需要渲染的文字**放进双引号**。

### ★ 对照后发现的根因：**我们用 `→` 描述时间序列，却要求 9 格并列画面**

我们实际发给模型的分镜提示词长这样：

    「生成一张3x3的九宫格电影故事板主图，采用国漫3D渲染，呈现中近景：林昭立于画面左侧，
      侧脸朝向右前方的壁挂无线电→机器爆出一阵沙沙电流声，她的眉峰微微一动→没有伸手去按通话键，
      只是把视线重新压回泛着暗光的透镜塔。冷蓝月光从她右肩后掠过…」

**`→` 是时间序列的写法**，而九宫格是**9 个并列格子**：模型只能把这一串动作画成
「同一个机位的相近构图」—— 这正是质检反复报的「九宫格面板雷同，仅头部微转、手部微移」。
换言之：**提示词与产出形态不匹配**，不是模型不行，也不是质检太严。

### 改进方向（按收益排序）

1. **把「动作推进」改成「9 个机位/景别的显式清单」** —— 官方要的 simple/clear 正好支持这种枚举式写法，
   比箭头串更可控；
2. **缩短分镜提示词**（当前偏长，官方建议简洁）；
3. **分镜链路接 `learned_prompt(kind="storyboard")`**，让已沉淀的 5 条雷同教训真正生效；
4. **统一生成侧与质检侧的段落标签口径**（要么生成侧写标签，要么质检侧不按标签判），
   这能直接消掉那 10 条反复出现的 prompt 类失败。
