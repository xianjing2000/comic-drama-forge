# 提示词模板：scene_grid_main —— 九宫格场景设定图主提示词（中文逐格版 · 单次出图）
# 用途：「场景九宫格（同一场地 9 机位）」的**逐格写死**版图提示词：开头一句任务宣言 →
#       场景设定 → 画面布局与内容（逐格列出 9 条「第N格：机位描述」）→ 视觉要求
#       （风格 / 一致性 / 禁忌）。**一次 T2I 直出整张 3×3**，取代「9 次独立出图 + PIL 拼接」。
# 调用位置：app/comfyui_client.py · build_scene_grid_prompt()（详见 app.py 资产 worker 的
#       scene 分支单次出图路径：SCENE_GRID_MODE and SCENE_GRID_ONESHOT）。
# 变量说明（运行时由 build_scene_grid_prompt 注入，编辑时不得删除这些占位符）：
#   {style}               画面风格锚定串（已剔除画幅/比例词）
#   {scene_prompt}        场景设定串（资产 reference_prompt_zh，已去人清洗）
#   {panel_plans}         逐格机位（每行形如「*   **第N格：** 机位描述」）
# ⚠️ 三条硬约束（勿违反，否则静默失效）：
#   1. 正文占位符**只能**是上面三个；prompt_templates 的 _VAR_RE 会把其它 {word} 也替换成空串。
#   2. 正文**不得出现** CHARACTER_WORDS / CHARACTER_QTY_RE 能命中的词（人物/人影/人群/士兵…），
#      否则 comfyui_client.sanitize_scene_prompt 会把整句丢弃、机位静默失效。
#   3. 括注里的 {style} / {scene_prompt} 之类仅用于阅读，不参与渲染（与 storyboard_grid_main 同风格）。

生成一张3x3的九宫格场景设定图，呈现同一个场地的9个不同机位与景别。

{style}

**场景设定：**
{scene_prompt}

**画面布局与内容：**
单张图像内均匀排列9个画面（3行3列），每个画面的左上角分别标注白色数字"1"至"9"。
9个画面是**同一个场地**在不同机位与景别下的取景：空间结构、建筑布局、材质纹理、家具陈设、光影色调必须完全一致，只有相机的位置、朝向与取景范围不同。

{panel_plans}

**视觉要求：**
*   **风格：** 整张图（含全部9个画面）必须是统一的风格化 CG 渲染，不是真人实拍照片；画面之间不画分隔边框，以画面内容自然分区。
*   **一致性：** 9格的墙面、地面、门窗、陈设位置必须对得上，是同一空间的不同视角，不要变成9个互不相关的场地。
*   **禁忌：** 除左上角的数字1-9外，画面中严禁出现任何文字、水印或标题；画面内不要有人。
