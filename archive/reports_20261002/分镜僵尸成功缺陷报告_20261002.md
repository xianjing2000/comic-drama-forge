## 二、证据链（缺陷 1 + 2）

### 2.1 症状

```
output/storyboards/逆天系统_全书/
  storyboard_manifest.json        ← 声称 success_count = 6 / 6
  （shot_01.png … shot_06.png 一张都不存在）

output/qc/逆天系统_全书/storyboard_scratch/
  shot_01_try1.png … shot_06_try1.png   ← 图全卡在暂存区
```

6 个条目**全部**带 `error = "get expected at most 2 arguments, got 3"`，
且 `file` 指向的正式图 `os.path.isfile` **全为 False**。

canvas 接口同步暴露：
```
card.storyboard = {exists: False, url: "", success: True,
                   error: "get expected at most 2 arguments, got 3"}
```

### 2.2 根因链

```
comfyui_client.generate_storyboard() 出图成功
        ↓
item.update({success: True, file: dst, url: ..., ref_count: ...})   ← 无条件先置位（约 6488 行）
item.pop("error")
        ↓
qc_client.check_image(...)  ← 崩在 cfg.get("image_ref_compare",
                                "image_blocking_ref_compare", True)  ← 三参！TypeError
        ↓
except Exception as shot_err:   ← 吞掉，只写 item["error"] = str(shot_err)
                                  ⚠️ 从不把 success 改回 False
        ↓
manifest: success=True + file=不存在的路径 + error=TypeError 文本  ← 僵尸条目
```

### 2.3 危害面

1. `manifest.success_count` 谎报，顶层判「已完成」；
2. canvas 的 `exists` 判 `isfile` → False，界面显示「无分镜图」（即用户报的现象）；
3. 下游 `video` 拿这个不存在的 `file` 当 I2V 首帧；
4. **`pipeline.probe_storyboard` 复核判失败 → 整集判失败 → 每轮全量重跑 6 镜**，
   而 `_ATTEMPTS` 只在内存 → 重启清零 → 死循环。实测 12:59→13:36 **烧了 4 轮约 40 分钟**.

## 三、为何「修了却还复现」—— 本次最大教训

修好 `qc_client` 后，13:25:59 与 13:36:18 **又跑了两轮，依旧全部报同一个错**。
一度误判「还有别处的三参 `get`」。实际原因：

```
Get-NetTCPConnection -LocalPort 5210 -State Listen
  → PID=33728   StartTime = 2026/10/2 10:13:35
```

**后端 10:13:35 启动，而修复 commit 在其之后才落盘 → 进程内存里始终是旧字节码。**

排除手法（留档）：
1. AST 扫全仓「三参 `get`」→ **空**（源码确实已无）；
2. 隔离复现 `check_image` 真实参数 → **score 88/100 passed=true**（质检本身能过）；
3. 源码与现象冲突 → 查进程 `StartTime` → 破案。

> **硬规则**：源码证据与运行现象冲突时，**先怀疑进程加载的代码版本**。

## 四、修复内容

### 4.1 `app/app.py`（僵尸成功复位，+92 行）

新增 `except _PromptQCBlocked` 单独分支，并让 `except Exception as shot_err` 一并复位：

```python
except _PromptQCBlocked as _pqb:
    item["success"] = False
    item["file"] = ""
    item.pop("url", None)
    item["error"] = str(_pqb)
except Exception as shot_err:
    ...
    item["success"] = False      # ← 关键：阻断/异常即非成功（fail-closed）
    item["file"] = ""
    item.pop("url", None)
    item["error"] = str(shot_err)
```

### 4.2 画布轮询 + 生成中态（缺陷 3 + 4）

  新路由 `/api/storyboards/scratch/<project>/<filename>`（复用 `_serve_safe` 防穿越）。
  **纯增量**：`exists`/`url` 语义未变。
- `frontend/src/pages/ProjectWorkbenchPage.tsx`：画布 **5s 轮询**（`fetchCanvas({silent})`
  不翻转 `loading`）；卡片三态渲染（正式图 → 生成中缩略图带 `?t=` 破缓存 + 角标 → 无图）。

## 六、遗留待决
