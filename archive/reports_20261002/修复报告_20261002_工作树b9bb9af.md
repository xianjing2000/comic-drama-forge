## 五、方法学沉淀（已写入项目记忆）

- **三道必跑门禁**：`py_compile` → **`pyflakes` undefined name** → 前端 **`npx tsc --noEmit`**。
- **`dict.get` 三参**只在左侧条件为真时暴露 → 只被「带参考图」的测试抓到。
- **提示词 / schema 字符串也要 lint 括号配对**（纯文本无报错，靠守卫抓）。
- **AST 孤岛测试依赖是递归的** → 别逐个列举，批量注入顶层函数 + 别名 + 常量。
- **写测试探针必须 `finally` 清理项目**，否则污染全局索引并让无关守卫假红。
- **`tsc` duplicate identifier 多为缓存残留**，先清缓存再改代码。
