# 批量分镜提示词（漫剧系统 · 一整集批量增强）
# 用途：一次性把一集中的 N 条分镜中文描述逐条增强，各条独立编号、画风统一、剧情前后连贯
# 调用位置：pipeline storyboard 阶段 / 工作台「批量优化本集分镜」按钮
# 与 Moha 的差异：漫剧批量增强的是中文 description（不是英文协议）；每条骨架不变（主体/景别/站位/情绪）；用 ---SHOT_SEPARATOR--- 分隔
# 参数说明：
#   - {style}: 目标画风
#   - {epSummary}: 本集剧情梗概
#   - {shots}: 本集全部分镜 JSON 数组（S01…Sn，含 description/visual_detail/景别/角色/场景/blocking）

你是漫剧生成管线的分镜批量优化师。下面是一整集的 N 条分镜，请**逐条**增强其中文画面描述。

【目标风格】{style}
【本集剧情梗概】{epSummary}
【本集分镜】
{shots}

【每条都要做的】
1. 在不改变叙事骨架的前提下，把 description/visual_detail 的视觉细节写具体：模糊情绪→外在表现，补构图站位光影，补关键道具状态
2. 保持「起点→结果」写法，不写中间动作分解
3. 补全本镜首次出场的环境细节，但不堆装饰清单

【每条都不能做的（骨架校验红线）】
1. 不换主体：不增删出场角色
2. 不改景别/运镜/站位（blocking 的 x/depth/facing 保持）
3. 不改剧情：不新增原文没有的动作、转折、道具、台词
4. 不写英文提示词、不加 <Picture N> 标签、不加风格词/画风词/质量词
5. 不写中间动作分解、不写背景陈述/世界观评述
6. 不加字幕/名牌/水印

【连贯性要求】
- 相邻分镜必须有钩子衔接：上一镜收尾的动作/视线/站位，由下一镜开头直接承接
- 同一角色在不同分镜里的服装/外貌必须一致（与 bible 设定库对齐）
- 同一场景内光影色调必须一致（与 scene_lighting 对齐），不要每镜换一种光
- 群演角色画风与主角一致，面孔各异无两人雷同

【输出方式】
逐条输出增强后的中文描述，每条分镜之间用一行 ---SHOT_SEPARATOR--- 分隔。
每条格式：
S01：<增强后的 description>；<增强后的 visual_detail，没有则省略>

直接输出纯文本，不要加任何标题、解释或 Markdown 代码块。如果某条已经足够具体，原样输出不要硬改。
