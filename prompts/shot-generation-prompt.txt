# 分镜生成提示词（漫剧系统 · novel_to_script ③build_shots_for_chunk）
# 用途：把一个分块原文压缩提炼成可拍摄的镜头 JSON（每集 20~30 镜、每镜 5~6 秒）
# 调用位置：novel_to_script.py - build_shots_for_chunk()
# 与 Moha 的差异：
#   1) 每镜 5-6 秒、每集 20-30 镜（不是快切）；相邻连续情节合并进同一镜，不逐动作拆镜
#   2) description 写「起点→结果」，不写中间动作分解（过程交给九宫格/视频阶段切片）
#   3) 站位 blocking 必填（3D 导演台）：name/x/depth/facing
#   4) dialogue 是数组 [{speaker, text}]，speaker 必须等于可用角色名；无台词写 []
#   5) 禁止写 prompt_h3 / 英文提示词——视频提示词由程序按 H3 规范自动构建
#   6) 本系统没有旁白，心理活动改成角色本人第一人称自语
# 参数说明：
#   - {title}: 剧名
#   - {chunkTitle}: 当前分块章节标题
#   - {chunkIndex}/{chunkTotal}: 块序号/总块数
#   - {shotsTarget}/{shotsCap}: 目标镜数/上限镜数
#   - {style}: 全剧风格
#   - {styleGuide}: 画面风格指南
#   - {charBrief}/{itemBrief}/{sceneBrief}: 可用角色/物品/场景清单（已登记资产）
#   - {chunkText}: 本段原文
#   - {summary}/{keyBeats}: 本段摘要/情节要点
#   - {prevTail}/{bibleBlock}/{contractBlock}/{cameraBlock}: 跨集上下文

【任务】为漫剧《{title}》的「{chunkTitle}」（第 {chunkIndex}/{chunkTotal} 段）编写分镜：至少 {shotsTarget} 个、上限 {shotsCap} 个。把下方原文**压缩提炼**成可拍摄的镜头，只保留推动剧情的关键情节（冲突/转折/关键动作/金句），纯背景铺陈直接删去、勿逐句照搬。

【粒度口径（务必先读）】本片目标是**每集 20~30 个镜头、每镜 5~6 秒**（不是每镜 2 秒的快切）。
- 镜数少了不等于少写情节：目标镜数变少时，请把相邻的连续情节**合并进同一个镜头**（一个镜头里可以容纳一个完整的动作过程、以及前后两段关键情节），而不是把原文情节丢掉。原文里的冲突/转折/关键动作/金句仍必须**全部**落到镜头里。
- 不要把一个完整动作拆成几个镜头：「抬手→握拳→挥出」是**一个**镜头里的连续动作，不是三个镜头。只有当**空间/时间/视角真的发生跳跃**（换了地点、跳了时间、要强调另一个主体）时才切镜。
- 不要为同一件事再补一个镜头：已经拍过的道具/手部，不要为了「规避人脸」再单独切一个几乎同画面的插入镜。

【描述粒度上限（务必先读）】
- description 写「**起点 → 结果**」：本镜开始时画面是什么、结束时画面变成了什么，**不写中间的连续动作分解**（「抬手→握拳→挥出」只写「攥紧拳头」这个结果）。
- 动作过程分解与逐格推进由视频/九宫格生成阶段负责。
- 每镜 description **≤ 80 字**，只写：主体、动作结果、关键构图位置、情绪落点。光线/氛围/背景只在推动剧情或首次出场时写一句，不逐句铺陈。

【全剧风格】{style}　【画面风格指南】{styleGuide}
{prevTail}{bibleBlock}{contractBlock}{cameraBlock}
【可用角色】{charBrief}
【可用物品】{itemBrief}
【可用场景】{sceneBrief}
【本段原文（先压缩提炼：只保留冲突/转折/关键动作/金句，纯背景铺陈直接删去，勿逐句照搬）】
{chunkText}
【本段剧情摘要】{summary}
【本段情节要点】{keyBeats}

【输出要求】严格只输出一个 JSON 对象，不要 markdown 代码块、不要解释文字，结构如下：
{"shots": [{
  "camera": "景别+运镜（必须取自运镜术语表，如 中景跟随/近景轻推，10 字以内）",
  "shot_type": "景别（只填以下值之一：大特写/特写/近景/中近景/局部/中景/全景/远景/大远景；局部=只拍手部/道具的插入镜；与 camera 里的景别词保持一致；无法确定写空字符串）",
  "camera_motion": "运镜（只填运镜词，优先 固定/轻推/轻摇/跟随/轻手持；无运镜的静止镜头填「固定」）",
  "location": "所属场景名（必须来自可用场景）",
  "description": "画面内容描述（≤80字，按「起点→结果」写：谁做了什么、做完后画面是什么状态、在画面什么位置；不写中间动作分解；外貌衣着/环境光线只在推动剧情或首次出场时写一句，禁止写背景陈述/世界观/来历评述）",
  "visual_detail": "画面补充细节（可选；当 description 之外还有本镜结果态里必须交代的关键环境/道具状态时写，≤80字；没有写空字符串）",
  "dialogue": [{"speaker": "说话角色名（必须与可用角色完全一致）", "text": "该角色台词（≤30 字；原文对话尽量原样保留；角色的自语/心声写成该角色本人的台词）"}],
  "emotion": "情绪（8 字以内）",
  "edit_reason": "剪辑动机（20~30字，具体说明这一镜为什么切/承担什么叙事功能，禁止可套用的空话）",
  "beat": "叙事节拍（只填「开场」「触发」「高潮」「收尾」四值之一；拿不准填「触发」）",
  "audio_cues": "音效/配乐提示（60 字以内，只写环境音/音效/配乐，不写人声）",
  "characters_in_shot": ["出场角色名"],
  "first_frame": "首帧画面（运动开始前那一刻的静态快照：画面主体与构图，40字以内；无明显运动变化写空字符串）",
  "last_frame": "末帧画面（运动结束后的终态，40字以内；与首帧相同或无运动时写空字符串）",
  "motion": "运动描述（严格区分【摄影机运动】推拉摇移跟升降 与【画面内运动】人物/物体自身动作；30字以内；静止镜头写空字符串）",
  "caption": "字幕（默认写空对象 {}；仅当本镜承担时空落点交代或集尾悬念时才写，形如 {\"text\": \"字幕文字≤20字\", \"kind\": \"时间地点/回溯/悬念 三值之一\"}）",
  "items_in_shot": ["出场物品名"]
}]}

【禁止输出 prompt_h3 字段】视频提示词由程序在生成阶段按 H3 规范自动构建（结合当次实际传入的参考图生成 subject_definitions/summary/retention_analysis/detailed_description/overall_soundscape/non_diegetic_music 六段）。你在剧本阶段并不知道最终配几张参考图，写出来的英文提示词缺少 <Picture N> 标签，反而会覆盖规范提示词导致出片偏离设定。因此不要写 prompt_h3、不要写英文提示词；把画面信息全部写进 description 即可。

【站位与动作（3D 导演台依赖，逐镜必填）】每一镜都要写：
① blocking：本镜出场角色的站位，每个出场角色一条，形如 {"name": 角色名, "x": left/center/right, "depth": front/mid/back, "facing": camera/left/right/back}。
  · x = 画面左右（left=画面左）；depth = 离镜头远近（front=更靠近镜头）；facing = 朝向，留空表示朝内。
  · 左右顺序与前后层次必须与本镜情节一致，禁止所有镜头套用同一套站位；角色互换攻守、走近/退开时，站位要跟着变。
② action：本镜的动作 beat——谁做了什么、动作从哪到哪（例：「羡进抬头直视赵天霸，右手缓缓握拳」）。不得留空，纯对话镜也要写神态与小动作。

【台词要求】dialogue 必须是数组，元素为 {"speaker": 角色名, "text": 台词}；speaker 必须精确等于「可用角色」中的名字，禁止写「旁白/众人」等未登记角色；无台词写 []（空数组），禁止写成字符串或 null。角色心理活动改写成该角色本人的自语台词时，speaker 仍写角色名（本系统没有旁白角色）。dialogue 只承载：原文对话、以及原文明确心理活动/独白改写的第一人称自语——第三人称叙述与背景补叙禁止写成任何角色开口的台词。

【台词预算】单个镜头的 dialogue 合计不超过 {speechBudget} 字（≈3.6 秒配音，按 4.5 字/秒）。台词过多时先精简冗余语气词与重复表述，仍超预算才拆成相邻镜头——配音按镜头时间轴铺，单镜台词超出镜头时长会被成片尾部静默截掉。

【音轨说明（本系统不产出旁白）】成片没有画外音解说，配音链路只读 dialogue：audio_cues 里写「雨声」「风声」这类音效不会产生人声。因此：① 有对话或自语的镜头必须写 dialogue，禁止把台词塞进 description/visual_detail/audio_cues；② 纯画面/纯动作镜头允许没有台词（成片留白，由音效与配乐铺底），但必须在 audio_cues 写明音效/配乐提示；③ 严禁凭空编造原文里没有的台词来凑人声——宁可留白，也不要无中生有。

【字幕/转场（caption）】本系统不产出旁白，时空跳跃靠字幕点明落点。只在三种情况写 caption：①上下集之间时间/地点跳变（kind=时间地点）；②本镜是时空回溯落点（kind=回溯）；③本集结尾仍有未回收伏笔需留悬念（kind=悬念）。其余镜头一律写空对象。caption.text ≤20 字，只写交代时空或悬念的短句；禁止复述台词、禁止写画面描述。

【硬性约束】
- shots 数组元素个数必须在 {shotsTarget} ~ {shotsCap} 之间
- 只把原文里推动剧情的冲突/转折/关键动作/金句落到镜头里，纯背景补叙、纯环境描写（不推进剧情）直接删去、不单独成镜
- name 字段必须与「可用角色/物品/场景」中的名字完全一致，不要新造名字
- 若上方给出「本集必须出现的原文金句」，必须把每句原样写进对应角色的 dialogue.text（不得改写、拆分、省略）
- 上一集已发生的事件禁止在本集重演
- 写完回看「剧情摘要/情节要点」，确认每个关键情节都有对应镜头；不要求逐句覆盖原文
